===== PAGINA 4 =====

 ¿Qué es Helm?
 Es un gestor de paquetes para Kubernetes que facilita la instalación, actualización y administraciones de
 aplicaciones.
 Similar a un npm o apt-get.
 Contiene paquetes de todo tipo: gitlab, jenkins, grafana, nginx, mysql.

===== PAGINA 5 =====

 Conceptos clave
 Chart
 Es el paquete en sí que contiene todos los recursos necesarios para ejecutar una aplicación en Kubernetes.
 Incluye todas las estructuras (deployment, service, etc), las cuales son configurables.

 Release
 Es una implementación específica del chart. Incluye versionado, lo cual hace que sea fácilmente posible hacer
 un rollback.

 Repositorio
 Es una fuente de charts desde donde se pueden descargar e instalar los mismos. Se puede actualizar
 fácilmente.

===== PAGINA 8 =====

 Creación e instalación de charts propios
  helm create my-python-app


 Estructura creada            values.yaml
  my-python-app               replicaCount: 1
  ├── charts
  ├── templates               # This sets the container image more infor
  │ ├── tests                 image:
  │ ├── _helpers.tpl            repository: my-python-app
  │ ├── deployment.yaml         # This sets the pull policy for images.
  │ ├── hpa.yaml                pullPolicy: IfNotPresent
  │ ├── ingress.yaml            # Overrides the image tag whose default
  │ ├── NOTES.txt               tag: "2.0.0"
  │ ├── service.yaml
  │ └── serviceaccount.yaml   # This is for the secrets for pulling an
  ├── .helmignore             imagePullSecrets: []
  ├── Chart.yaml              # This is to override the chart name.
  └── values.yaml             nameOverride: ""
                              fullnameOverride: ""
